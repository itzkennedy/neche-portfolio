BAYA

BAYA is a student marketplace built for university communities - a place where students can discover and buy from sellers within their own campus. I founded it and took it from an idea to a live product, starting from a problem I saw daily: buying and selling happened in scattered WhatsApp groups, with no order and no way to trust who you were dealing with.

Health tracker2025

MedTrack

MedTrack is a medication adherence tracker I built during my engineering internship at APIN Public Health Initiatives. I set up the full-stack architecture - a React frontend, a Node/Express API and a Supabase database - and designed it around helping patients stay on schedule, with a family member able to keep an eye on adherence.

  • Full-stack setup - React (Vite) client, Express API, Supabase schema
  • Database models patients, medications, dose schedules and adherence logs
  • Domain designed around taken / skipped / snoozed logging and patient ↔ caregiver links
  • Wireframes and ER diagram documented in docs/
React Node.js / Express Supabase JWT auth Vite

Developer tool2026

Vulcan

Vulcan is an AI coding agent built in Python and TypeScript - a tool that takes an instruction in plain language, reads the code in a project, and works with it to generate, modify or debug that code. It scans codebases for bugs, exposed secrets and missing error handling, then auto-fixes them. It runs offline (Ollama) or online (DeepSeek) with automatic fallback.

  • Built around a scanner → fixer → agent pipeline of Python modules
  • Detects bugs, exposed secrets and missing error handling, then fixes them
  • Offline (Ollama) or online (DeepSeek) with automatic fallback
  • Packaged as a VS Code extension, with a file-protection vault and loop-detection safeguard
Python TypeScript LLM / AI agents Ollama / DeepSeek VS Code extension

Tactics board2026

NecheBall

NecheBall is a football tactics board - set up a formation, drag players into position, and plan plays with arrows and lines. The interesting part isn't the features, it's the timing: I took it from idea to a working, live app in about a day, as proof I can ship fast rather than just talk about it.

  • Formations - 4-3-3, 4-2-3-1, 3-5-2, 5-3-2, and more
  • Real tactic presets - Guardiola, Klopp, Mourinho, Flick and others
  • Draw tools - tactical arrows and lines, undo, free positioning
  • Save as PNG, share a lineup link, and edit a copy
