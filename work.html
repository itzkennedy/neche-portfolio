MedTrack

A medication management system for patients and caregivers.

The problem

Medication can be easy to forget, and caregivers may not have a simple way to know whether doses are actually being taken.

What I built

A medication management system with separate patient and caregiver experiences for scheduling, logging and tracking medication.

  • Full-stack build - React (Vite) client with routing, Express API, PostgreSQL schema
  • Patient and caregiver roles, with OTP verification and JWT/bcrypt auth
  • Dose logging for taken / skipped / snoozed, plus adherence tracking over time
  • Caregiver invites, medication schedules and reminders, installable as a PWA
My role

Built during my internship at APIN. I set up the React + Node/Express + PostgreSQL architecture and the data model behind it.

Vulcan

I built an AI coding agent that can work directly with an existing codebase.

The problem

Working through a codebase manually can turn relatively simple development tasks into repetitive work: finding the right files, understanding how pieces connect, locating issues and then making changes across the project.

What I built

Vulcan lets me describe a coding task in plain English, inspect the relevant project files and make changes across the codebase.

  • A scan → fix → agent pipeline, built as seven focused Python modules
  • Audits a codebase for bugs, hardcoded secrets and TODOs, then applies corrections
  • Runs fully offline against a local model (Ollama) or online via an API, with automatic fallback
  • Keeps changes bounded while it works - a file vault with backups and a loop guard against runaway edits
  • Writes a report at the end so you can see exactly what changed and why
My role

I designed and built Vulcan, including the workflow that allows the agent to work with an existing codebase.

Why I built it

I didn't want another chatbot that simply returned code in a conversation. I wanted something that could work with the project itself.

A conversation-based tool expects you to do the project work around it. Vulcan was built the other way round: point it at the codebase, and it does the work of finding and changing what needs to change.
